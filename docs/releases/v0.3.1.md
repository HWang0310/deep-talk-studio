# DeepTalk Studio V0.3.1 — Discovery Gate Hardening

V0.3.1 是 V0.3 Topic Discovery 的正确性修订，不增加 Script Agent、素材、视觉、剪辑或发布能力。

## 主要修订

- Codex Source Seed 只有在实际打开页面的 inspection manifest 中出现后才会标为 `manual_open`。
- Candidate Artifact 的资格、理由、推荐、评分、展示、首选和统计全部可确定性重新推导；被篡改的工件会被拒绝。
- Preflight 只计入不同的已检查合格来源方向，收紧 URL、publisher 与 host 重复处理。
- 修复时间一致性、类别补位、Raw Candidate 最小池和无效 `--count` 行为。

## 兼容性与限制

Topic Candidate Set 仍为 `0.3`，Research Report 和 FactCheck Artifact 仍为 `0.2`。旧 Candidate Set 可按 legacy provenance 状态读取，但不会自动变成新检查过的来源。V0.4 Script Agent 仍未开始。

## 验证

- 113 项自动测试全部通过。
- Broad 与 Tech / Business 真实评测均形成 5 个不重复候选并完成编号交接。
- Social / Public 真实搜索仅得到 1 个 Raw Candidate，系统按规则拒绝生成不完整 Candidate Set；Top 5 相关检查如实标为不适用。
