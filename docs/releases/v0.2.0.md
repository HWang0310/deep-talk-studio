# DeepTalk Studio V0.2.0

V0.2 把 Research Report 从“结构完整”升级为“证据和核查过程可机器追踪”。

## 主要能力

- Research Report 0.2 和正式 Evidence Ledger；
- 完整嵌套 Schema 校验与中文错误提示；
- OpenAI API / Codex 两种 provenance 记录方式；
- Research Draft 与独立 Fact Check 两阶段工作流；
- 高风险队列、来源去重、转载识别和透明质量 Gate；
- 不可覆盖的修订历史和 V0.1 迁移；
- 三类真实公开题材端到端编辑评测。

## 验证结果

- 68 项自动测试全部通过。
- 官方 Skill Creator 校验通过。
- 离线示例、V0.1 迁移、修订防覆盖和干净环境安装通过。
- 真实评测中，两份证据充分报告进入 `reviewed`；一份快速变化的公共安全热点因高风险数据未独立确认而保持 `draft`。

## 已知限制

- 当前仍没有 Topic Discovery、Script Agent、素材、视觉、剪辑或发布功能。
- 来源转载识别是保守的第一版启发式规则，未知情况会保留为未知，不能覆盖人工判断。
- 本次环境没有用户 API 密钥，因此 API 联网链路使用受控模拟测试；Codex Skill 联网链路已经用三类真实题材验证。
- `reviewed` 不代表可直接发布，也不会自动写稿；未来进入 Script Agent 前仍需用户确认。

## 升级说明

旧 0.1 报告可使用：

```bash
./scripts/deeptalk migrate 旧报告.json
```

迁移结果会保持 `draft`，不会伪造已经执行过独立事实核查。真实报告仍默认保存在本机 `reports/`，不会进入 GitHub。
