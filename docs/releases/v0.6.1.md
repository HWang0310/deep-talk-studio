# DeepTalk Studio v0.6.1

V0.6.1 是 V0.6 的生产收口版本，不进入 V0.7。

## 完成内容

- timeline、bar、comparison、diagram 改为真正逐元素 Motion；两个 renderer 消费同一份 Python Core `scene_payload`。
- Display Text 对无数字事实同样执行语义 grounding；固定机器短语以外均需相关 Claim/Evidence。
- Production QA 改为 typed check → blocking issue → gate，验证或预览失败不能与 pass Gate 并存。
- raw PDF 只保留 provenance；只有 V0.5 已审 PNG/JPEG/WebP capture 可进入图片 renderer。
- rough preview 只有 MAPREVIEW 确实 ready 时才宣称成功。
- 公开 Release assets 提供虚构三柱图的 Remotion/HyperFrames MP4、contact sheet 与 evidence summary。

## 验证

- unittest：267 total，266 executed pass，1 default-skipped real-render integration。
- 显式真实 cross-renderer integration：pass。
- Remotion 4.0.507：npm ci、lint、typecheck、compositions、Studio、render/still、ffprobe 全通过。
- HyperFrames 0.7.106：npm ci、doctor、lint、validate、inspect、preview、render、ffprobe 全通过。

## 仍不包含

字幕、BGM/SFX、最终剪辑、标题封面、发布、TTS 和音频对齐仍不属于 V0.6.1。
