# DeepTalk Studio V0.3.0 — Topic Discovery

发布日期：2026-08-10

## 用户现在能做什么

在 Codex 中直接说“今天讲什么？”“帮我找几个科技选题”或“最近社会热点有什么值得讲？”。系统默认给最多 5 个候选并明确一个首选。回复 `1` 或 `研究 1` 后，不需要再复制标题，所选题会直接进入既有 Research Draft → Independent Fact Check → Quality Gate。

## 本版重点

- 新增版本化 Channel Profile 和 Topic Candidate Set 0.3。
- 最近 72 小时 + 最近 14 天持续事件的新进展规则。
- Source Seed 轻量预检、风险提示、watch / reject、事件去重和类别多样性。
- 可解释的固定评分：可核查性 30%、深度冲突 25%、新鲜度 20%、频道匹配 15%、公开关注信号 10%；总分由代码计算。
- 新增 `discover-topics` Skill、自动化 CLI、不可覆盖的 discovery 历史和编号到 Research Handoff 接口。

## 验证

- 101 项自动测试通过。
- 已运行 Broad、Tech / Business、Social / Public 三类真实公开 Discovery 评测；资料不足的高风险线索保持观察或拒绝，不进入推荐。
- 保持 V0.2 的 Research Report 0.2、FactCheck Artifact 0.2、独立来源规则和质量 Gate；模式 A 直接研究回归测试继续通过。

## 已知限制

- Topic Discovery 只判断“值不值得继续研究”，不裁决最终事实；Source Seeds 不能替代 V0.2 Evidence Ledger 或独立 Fact Check。
- Creator attention 不是必需信号，且不会收集创作者稿件或字幕。
- 没有 API Key 时，普通用户直接在 Codex 中自然语言使用 Skill；CLI 联网模式会给出明确提示。
- 本版没有 Script Agent、素材、视觉、剪辑或发布。
