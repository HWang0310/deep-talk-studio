# DeepTalk Studio V0.5.1 — Material Gate Hardening

## 本次更新

- 可直接使用素材现在必须同时证明素材页和权利依据页确实被打开，且工具记录相同；普通搜索结果、模型自称或伪造许可证都不能越过 Gate。
- 原创时间线、柱状图、对比图和关系图的内部引用逐条回查已批准 Research，错误的主张、证据或数字会在渲染前拒绝。
- 已审素材包不再只相信 JSON 与普通摘要：打开时会重建 r1、读取独立 provenance 和 Review Artifact，再重新得出 r2。
- SVG 允许标准 namespace，同时继续拒绝脚本、事件和外部资源；截图页码与真实图片格式也会检查。

## 验证

- 完整自动测试：219 项通过。
- 保持无 API Key 的受控真实/合成评测；完整素材和工作稿继续不公开上传。

## 已知限制

本版仍不创建 Remotion、HyperFrames、完整视频、剪辑、字幕、音频、封面或发布流程。工程校验不替代发布前的人类编辑和法律判断。

## 升级说明

旧 V0.5.0 已审素材包没有 V0.5.1 所需的独立 provenance artifacts，不能被静默提升为可信包。需要从同一份已审稿件和 Research 重新准备素材并执行一次独立 Material Review。
