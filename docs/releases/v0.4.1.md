# DeepTalk Studio V0.4.1

V0.4.1 is a focused Script Gate correctness release. It does not add new
content-production features and does not start V0.5.

## Fixed blockers

- A failed Review check can no longer coexist with no matching issue and still
  produce a passing gate. The eight factual-safety checks require a matching
  blocking issue; all other failed checks require their mapped issue.
- A `reviewed` Script now proves its passing Review through machine-owned state,
  the original r1 Review Artifact, fixed report/script binding, and a content
  SHA-256 digest. Manual status or review-field edits fail validation/loading.
- Beat identity is stable across revisions. Inserts receive new monotonic IDs,
  removed IDs retire permanently, and retained/moved Beats preserve identity so
  comparison reflects real changes.

## Compatibility

The Script Draft and Script Review Artifact major versions remain `0.4`.
Legacy V0.4.0 drafts remain readable. A legacy `reviewed` Script with no
verifiable V0.4.1 linkage is intentionally not trusted and must be re-reviewed.

## Validation

- 165 automated tests pass, including all 151 tests recorded for V0.4.0.
- Controlled A/B approved workflows each completed Writer → r1 → 15-check
  Review → linkage-verified reviewed r2 → Teleprompter.
- A reviewed-but-unapproved Research input was refused before Writer.
- The synthetic `factual_grounding=fail` with no issue was rejected before any
  reviewed Script could be created.

Full evaluation artifacts remain ignored; only the decontented
[`evaluations/v0.4.1-summary.json`](../../evaluations/v0.4.1-summary.json) is
public.

## Scope boundary

Material Search, Visual Assistance, images, video, Remotion, HyperFrames,
editing, captions, publishing metadata, and distribution are not included.

GitHub provides source ZIP/TAR archives for this release. No empty GitHub
Package is published.
