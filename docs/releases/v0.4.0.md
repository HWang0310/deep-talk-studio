# DeepTalk Studio V0.4.0

V0.4.0 adds the first Original Script Agent. A fact-checked Research Report now becomes eligible for writing only after an explicit user confirmation is saved as a new immutable Research revision.

## Highlights

- Script Profile, Script Draft and independent Script Review contracts at version 0.4.
- Beat-level Claim / Evidence grounding with explicit fact, attribution and analysis boundaries.
- Hard gates for unapproved research, high-risk unchecked facts, direct avoid-claim usage and machine-field tampering.
- Separate Writer and Reviewer passes with no Web Search and 15 mandatory review dimensions.
- Editor and clean Teleprompter Markdown outputs.
- Immutable script revisions, natural-language duration controls and revision comparison.
- Three real workflow evaluations, including verified refusal of an unapproved input.

## Validation

- The full automated suite, Python compilation, CLI smoke tests, JSON parsing and all three repository Skills were verified before release.
- Two real approved reports produced reviewed scripts with full must-keep coverage; a reviewed but unapproved report exited with code 2 and created no files.

## Known limits

- Duration is estimated from spoken Chinese characters and still needs a human read-through.
- Semantic paraphrases of avoid-claims and originality risks require the independent Reviewer; direct phrase use is blocked in code.
- A reviewed script is ready for human editing, not approved for automatic publication.
- Material search, visual generation, editing and publishing remain outside V0.4; V0.5 has not started.

GitHub automatically provides ZIP and TAR source archives for this release. No empty GitHub Package is published.
