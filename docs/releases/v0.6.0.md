# DeepTalk Studio v0.6.0

V0.6.0 新增 Motion Production Layer：从通过 V0.5.1 canonical Gate 的 Material Package 生成 Production Plan、Remotion 或 HyperFrames project、真实 MP4/PNG、rough visual preview、Motion Asset Manifest 和 Production QA。

## 核心安全边界

- reference-only、permission-required、rejected、missing 和 tampered asset 不进入 renderer。
- 屏幕数字与日期必须重新绑定 approved Research。
- 普通制作只使用一个 renderer，两个 adapter 共用同一 Plan/Profile/Manifest/QA。
- 计划、输出和渲染工程不覆盖且默认不进 Git。
