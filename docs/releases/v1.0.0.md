# DeepTalk Studio v1.0.0

> Release-note source prepared for the eventual GitHub Release. The release candidate still requires Nexus exact-SHA and PR approval. No `v1.0.0` tag, GitHub Release, or package publication exists yet.

Until that separate release gate completes, the latest formal release remains `v0.6.1`.

DeepTalk Studio v1.0.0 brings the complete creator-led workflow together as **one main capability plus four auxiliaries**. It helps a creator research and write a defensible spoken-video script, then prepare source-backed or generated visual options without taking over the final edit.

## What is included

### Main — writing

- topic discovery and research with source provenance;
- independent fact checking, uncertainty, and counter-evidence;
- Content Thesis review and explicit human confirmation;
- a creator-ready Reviewed Script with factual and quality gates.

### Four auxiliaries

1. **Insert materials:** prepares source-backed material with provenance, rights, factual binding, capture, and QA.
2. **MG:** explicitly invokes the pinned MG visual plugin for a selected segment.
3. **Illustrated Metaphor / 小黑漫画:** explicitly invokes the pinned illustrated visual plugin.
4. **Hand-drawn Animation:** explicitly invokes the pinned hand-drawn visual plugin.

The generated visual families are opt-in and invocation-scoped. DeepTalk runs only the family the creator names. Candidate Portfolio, Asset Pack, Edit Map, real A-roll timing, plugin failure isolation, and read-only Finished Cut Review remain available as supporting infrastructure.

## Safety and creator control

- Final Clean A-roll remains the only production timing source.
- Source, rights, factual, digest, lineage, artifact, and media QA fail closed.
- The creator chooses whether and how to use each material and owns the final NLE edit.
- Committed plugin configuration remains disabled by default.

## Known limitations

- No automatic visual-family selection, winner ranking, overlap resolution, or final-material choice.
- No take selection, A-roll cleanup, automatic edit, NLE project generation, final-cut output, or publishing.
- Product Architecture V2 Phase D generated-provider migration, Phase E REAL_MATERIAL plugin migration, and Phase F production adoption have not started.
- MG Quality V2 and broader visual-quality work remain future improvements.
- Phase 6's Owner-visible micro demo remains held for Owner review and is not a release acceptance claim.
- Locked local renderer toolchains currently report npm advisories but no critical finding. Their affected URL/config/archive/HEIF paths are outside the repository-controlled fixed-input flow, and HEIF is not an allowed material type; dependency remediation remains a separate reviewed change.

## Upgrade notes

- The Python distribution version changes from `0.6.1` to `1.0.0`; no new dependency or package format is introduced.
- Existing V1 artifacts and compatibility readers remain supported and are not rewritten.
- Plugin identities, versions, commands, timeouts, exact revisions, and disabled-by-default behavior are unchanged.
