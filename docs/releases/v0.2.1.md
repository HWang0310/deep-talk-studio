# DeepTalk Studio V0.2.1

V0.2.1 是 **Quality Gate correctness / provenance / independence hardening**，不是新增用户功能。正式 Research Report 和 FactCheck Artifact 继续使用 Schema 0.2，质量阈值保持不变。

## 修复内容

- confirmed fact 只有在来源为 `supports`、provenance 已匹配、明确标为 `independent` 且 group 不同时，才算两份独立确认；
- `unknown`、`related`、`duplicate`、`syndicated` 不再被误算为独立确认；
- context-only、未匹配 attribution、重复与转载来源不能意外刷高相关质量指标；
- OpenAI API Research 只要求模型生成研究内容，报告身份、revision、状态、quality 和审批信息由程序确定；
- Fact Check 新来源与 r1 来源统一做 URL 规范化、重复、同发布者、转载和独立性归组；
- 修复重复 URL 在二次规范化时从 duplicate 变成 syndicated 的不稳定行为。

## 验证结果

- 85 项自动测试全部通过，包含原有 68 项和新增回归测试；
- sample、validate、prepare-draft、review-report、V0.1 migration 和 revision overwrite protection 通过；
- Skill 校验、Python 3.9 兼容、干净环境安装、源码编译和密钥扫描通过；
- 三类真实题材重新运行：2 份 `reviewed`，1 份快速高风险热点按预期保持 `draft`。

## 范围说明

本版本没有开始 V0.3 Topic Discovery，也不包含 Script Agent、素材、Remotion、HyperFrames、剪辑或发布。通过 Gate 的报告仍需用户明确确认，才可能进入未来 Script Agent。
