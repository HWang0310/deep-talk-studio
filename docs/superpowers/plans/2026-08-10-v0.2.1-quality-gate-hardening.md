# DeepTalk Studio V0.2.1 Quality Gate Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Correct V0.2 independent-source counting, make API Research content-only, and deterministically group Fact Check sources before trust.

**Architecture:** Keep the public Research Report and FactCheck Artifact at version 0.2. Add one API-only draft schema, canonicalize combined Research/FactCheck sources before validation and storage, and derive all Gate metrics from usable evidence rather than model-declared metadata.

**Tech Stack:** Python 3.9+ standard library, `unittest`, JSON Schema subset implemented in-repo, GitHub Releases.

## Global Constraints

- Release version is `0.2.1`; Report and FactCheck Artifact schema versions remain `0.2`.
- Quality thresholds remain unchanged.
- Do not implement Topic Discovery, Script Agent, materials, video, editing, or publishing.
- Unknown independence must never be promoted merely because group IDs differ.
- Do not force-push or rewrite GitHub `main` history.
