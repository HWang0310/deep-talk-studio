# DeepTalk Studio V0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Research Report 升级为来源、证据、独立核查、质量门槛和修订历史都可机器追踪的 0.2 工件。

**Architecture:** 保留“AI 提供判断、Python 核心执行确定性契约”的边界；Research 与 Fact Check 是两次独立调用和两个 Schema。递归 JSON Schema、业务引用校验、来源对账、质量计算和存储历史分别放在小型模块中。

**Tech Stack:** Python 3.9+ 标准库、`unittest`、OpenAI Responses API Web Search、仓库级 Codex Skill。

## Global Constraints

- 不实现 Topic Discovery、Script Agent、素材、Remotion、HyperFrames、剪辑或发布。
- 所有入口执行同一完整校验，不削弱 Schema 迁就模型输出。
- 真实报告留在 Git ignore 的 `reports/`。
- 不保存密钥、长篇版权原文或未经审查的真实内容到 Git。
- 不重写远程 `main` 历史，正式完成后创建 `v0.2.0` GitHub Release。
