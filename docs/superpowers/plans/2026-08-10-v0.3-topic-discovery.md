# DeepTalk Studio V0.3 Topic Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user receive five safe, explainable recent video-topic candidates and select one by number to start the existing V0.2 research workflow.

**Architecture:** Create a separate Candidate Set 0.3 contract and deterministic discovery core. Provider/Codex search returns only raw candidate judgments and Source Seeds; local code owns identity, provenance reconciliation, eligibility, weighting, ranking, persistence, latest selection and the handoff brief. Keep Research Report 0.2 and its quality gate unchanged.

**Tech Stack:** Python 3.9+ standard library, `unittest`, in-repo JSON Schema subset, OpenAI Responses API web search, GitHub Releases.

## Global Constraints

- Package version is `0.3.0`; Research Report and FactCheck Artifact remain version `0.2`.
- Default discovery window is 72 hours; an event started in the prior 14 days is eligible only with a 72-hour new update.
- Score weights are researchability 30, depth_conflict 25, freshness 20, channel_fit 15, attention_signal 10; code computes total score.
- Creator attention is optional and never factual evidence; never download scripts, subtitles or content for imitation.
- `discoveries/` history is ignored; no secrets, real research reports or real discovery lists are committed.
- Do not force-push or rewrite GitHub `main` history.
