# DeepTalk Studio V0.6 Motion Production Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 canonical V0.5.1 Material Package 转换成真实可用 motion assets、rough preview 和可复验 Production QA，并发布 v0.6.0。

**Architecture:** Python Core 生成唯一 Production Plan 并拥有全部安全/事实/QA Gate；Remotion 与 HyperFrames 通过同一 adapter boundary 只负责表现和真实渲染。真实项目与视频保存在 gitignored immutable storage，仓库提交锁定模板、契约、测试和去内容化评测。

**Tech Stack:** Python 3.9+ 标准库、Remotion 4.x/React/TypeScript、HyperFrames/HTML/GSAP、Node 22、FFmpeg/ffprobe、unittest。

## Global Constraints

- 项目版本固定为 `0.6.0`，GitHub Release 固定为 `v0.6.0`。
- Production Workflow 只接受 canonical `reviewed` / `reviewed_with_warnings` Material Package，`research_update_required` 必须停止。
- 默认画布 1920×1080、16:9、30 fps、Bilibili、真人 A-roll 优先。
- `reference_only`、`permission_required`、`rejected` 不能进入 renderer 或输出。
- 普通执行只渲染一个 renderer；同计划双渲染只用于兼容性评测。
- 不做 TTS 用户声音、字幕、BGM、标题封面、上传发布或完整最终成片。
