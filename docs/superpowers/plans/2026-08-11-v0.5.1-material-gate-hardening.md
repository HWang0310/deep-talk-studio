# V0.5.1 Material Gate Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden Material Package provenance, nested Visual grounding, reviewed-package revalidation, SVG safety and capture validation without entering the production layer.

**Architecture:** Preserve V0.5 interfaces while adding machine-owned r1 provenance artifacts. Reconstruct r1 from approved inputs and provenance, then derive r2 solely from the linked Review Artifact during load. Keep all authorization decisions fail-closed.

**Tech Stack:** Python 3.9 standard library, unittest, JSON Schema, immutable local artifacts.
