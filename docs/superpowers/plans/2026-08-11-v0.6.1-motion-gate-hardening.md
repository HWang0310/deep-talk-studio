# DeepTalk Studio V0.6.1 Motion Semantics & Production Gate Hardening Implementation Plan

> 本计划落实 ChatGPT 已批准的 V0.6.1 Review。执行使用严格 TDD，每个行为先证明旧实现会失败，再实施并回归。

**Goal:** 收口 V0.6：四类 Visual 真实逐元素运动，非数字事实文字可追溯，所有 renderer check 失败关闭 Gate，原始 PDF 永不进入图片 renderer，并发布 `v0.6.1`。

**Architecture:** Python Core 生成唯一严格 `scene_payload` 并拥有全部事实/权利/QA 决策；Remotion 与 HyperFrames 是只表现、不补事实的薄 Adapter。

**Tech Stack:** Python 3.9+ 标准库、Remotion 4.x/React/TypeScript、HyperFrames/HTML/GSAP、Node 22、FFmpeg/ffprobe、unittest。

## 全局约束

- 版本固定 `0.6.1`，Release 固定 `v0.6.1`。
- 不进入 V0.7，不添加字幕、音频、最终剪辑、封面或发布功能。
- 四类 Motion 不得把 V0.5 SVG 当作动画主体。
- raw PDF 不得进入 CanvasImage/img；只允许 V0.5 已审 image capture。
- check → issue → gate 只能由 Core 推导，任一关键 check fail 必须 fail closed。
- 所有 synthetic evidence 必须虚构、无版权风险、可公开。
