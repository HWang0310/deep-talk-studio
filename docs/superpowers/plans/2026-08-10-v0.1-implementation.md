# DeepTalk Studio V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a repository-scoped Research Skill and a tested Python workflow that turns a topic into a source-backed Markdown/JSON Research Report.

**Architecture:** Codex performs judgment-heavy web research through a focused repo Skill. A dependency-free Python core owns the versioned report contract, validation, rendering, persistence, and an optional OpenAI Responses API adapter.

**Tech Stack:** Python 3.9+ standard library, `unittest`, Codex Agent Skills, OpenAI Responses API, Markdown, JSON.

## Global Constraints

- V0.1 implements only project foundations and Research Workflow.
- Separate confirmed facts, media reports, party statements, commentary, and unverified information.
- Important claims retain source IDs and clickable URLs.
- Do not copy, wash, or imitate another creator's script or distinctive expression.
- Keep future agents modular without prematurely implementing them.
- Do not store API keys, tokens, passwords, or other credentials.
