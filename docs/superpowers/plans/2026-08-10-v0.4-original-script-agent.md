# DeepTalk Studio V0.4 Original Script Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the immutable Research approval flow and a grounded, reviewed, revision-safe Original Script Agent released as V0.4.0.

**Architecture:** Keep Research Report 0.2 unchanged and add separate Script Draft and Script Review 0.4 contracts. Focused modules own approval, profile, grounding, rendering, review, storage, and orchestration; API/Codex models only provide editorial judgments, while Python owns identity, metrics, gates, and state.

**Tech Stack:** Python 3.9+ standard library, unittest, JSON Schema subset, Codex Skills, OpenAI Responses API without tools for Script calls, GitHub Releases.

## Global Constraints

- Do not add Material Search, visual generation, Remotion, HyperFrames, editing, subtitles, thumbnails, publishing metadata, publishing, or analytics.
- Do not change Research Report 0.2, FactCheck Artifact 0.2, or Topic Candidate Set 0.3.
- Script Writer and Reviewer never use Web Search.
- Real Research Reports and Scripts stay in gitignored local directories.
- Do not force-push or rewrite GitHub `main` history.
