# DeepTalk Studio V0.5 素材与画面辅助设计

日期：2026-08-11  
状态：依据 ChatGPT 正式 Review 任务实施

## 目标与边界

V0.5 把一份经过 V0.4.1 独立审查的口播稿，转成可核查、可取用、可复核的 Material Package 0.5。系统给出逐段画面提示，搜索并检查候选素材，保守判断权利状态，安全保存确有复用依据的文件，并用已批准 Research 数据生成原创静态 SVG。

本版本不生成完整视频，不实现剪辑时间线、字幕、音乐、封面、上传、发布或运营分析。Remotion 和 HyperFrames 只作为未来 render target hint；V0.5 不创建它们的工程或 Composition。

## 正式输入门槛

Material Workflow 同时接收：

- `status=reviewed` 的 Script Draft 0.4；
- 与 Script 精确绑定的 `report_id + report_revision` Research Report；
- V0.4.1 `review_state` 指向的真实、通过的 Script Review Artifact；
- Material Profile 0.5。

入口重新执行既有 Script validator。草稿、手改状态、缺失或伪造 Review Artifact、内容指纹不一致、Research 修订不一致均在搜索和写文件前拒绝。

## 工件与状态

机器接口为 Material Package JSON；Markdown 仅是派生阅读版。顶层至少包括：

- 工件身份、revision、创建与检查时间；
- Script ID / revision / 内容摘要；
- Research ID / revision；
- Profile 版本和包状态；
- Cue Sheet、Materials、Generated Visuals、Gaps；
- Research Update Required、Warnings、Review State。

初始包为 `draft`。独立 Material Review 创建不可覆盖的新 revision，状态只能由代码推导为：

- `reviewed`：可用项通过且无警告；
- `reviewed_with_warnings`：危险项已隔离，仍有安全替代；
- `research_update_required`：搜索发现可能改变稿件或图表的新事实；
- `blocked`：没有安全可用方案或存在包级阻断。

## Cue Sheet

Cue 不按音频时间码定位，而使用短且必须精确存在于对应 Beat 口播中的 `placement_anchor`。每个 Cue 包括 Beat、作用、建议秒数、首选素材类型、优先级和理由。没有必要的 Beat 可以没有 Cue；程序拒绝重复锚点、错误 Beat、过长或不存在的锚点。

画面作用固定区分 `evidence`、`context`、`illustration`、`transition`。Illustration 永远不能充当 Evidence。

## Provenance 与权利判断

模型只能提出候选和初步判断。真实页面检查由独立 inspection manifest 证明，包含 URL、检查时间、检查方式和工具引用。搜索结果摘要不算打开页面；未在 manifest 中匹配的 URL 保持 `unmatched`。

明确复用权利也需要 rights manifest，包含状态、依据、许可证 URL（适用时）、检查时间和工具引用。系统不从发布者名称或素材类型推断版权。

权利状态：`public_domain`、`explicit_reuse_allowed`、`creative_commons`、`official_press_asset`、`editorial_reference_only`、`permission_required`、`unknown`、`avoid`。

资格由代码失败关闭：只有真实检查且权利属于前四类的远程素材可以成为 `ready_to_use`；普通新闻、视频或未知权利素材只能 `reference_only`；需许可为 `permission_required`；伪造、错配、避免使用或危险文件为 `rejected`。原创 SVG 在 grounding 校验通过后可 `ready_to_use`，但其事实内容仍必须回链 Research。

## Claim / Evidence 绑定和 Research 更新

Evidence 素材必须绑定当前 Research 的 Claim 与 Evidence Link，且 Link 必须关联这些 Claim。Context 可以只绑定 Claim；Illustration 标记 `illustrative_only=true`，不得伪造证据绑定。

素材搜索不是新的 Research。若出现冲突、更新或影响现有论述的新信息，Provider 只提交 `research_update_signals`。程序将 Package 标成 `research_update_required`，列出受影响 Beat、Claim、原因与新 URL；不自动改稿、不改 Research、不把新信息写进图表。

## 安全获取与截图

下载器仅处理公开 HTTP(S)，拒绝本机、内网、非 HTTP、危险 MIME、超限文件、状态异常、重定向到非公开地址和目标覆盖。允许类型限于静态图片、SVG、PDF 和纯文本；不执行 HTML、JavaScript、宏或可执行文件。默认上限 25 MiB。

只有权利明确、技术安全且 `ready_to_use` 的远程素材可自动保存。网页/PDF 截图使用“登记已捕获本地静态文件”的方式进入包，并记录原页面、页码、截取区域、说明、它能证明什么和不能证明什么。视频只保存页面、发布者、标题、建议起止时间和用途；没有明确权利时不下载。

## 原创 Visual Spec 与 SVG

Visual Spec 0.5 支持 `timeline`、`bar`、`comparison`、`diagram`。它包含画面标题、数据/事件/节点、Claim 与 Evidence Link、署名、16:9 安全区、建议时长、动画意图、样式 token、屏幕文字和未来 render target hints。

Timeline 事件必须与 Research timeline 日期和 Claim 绑定一致；数值图的数据必须能在绑定 Claim 文本中找到对应数值；所有引用 ID 必须存在且关系正确。程序拒绝虚构数字、Research 外事件和未绑定事实。

最小 renderer 只用标准库生成 1920×1080 SVG，覆盖时间线、柱状图、比较图和简单关系图；高对比、可读、XML 转义、包含 attribution metadata，不调用外部资源。PNG 为可选能力，本版本不承诺。

Profile 默认 B 站 1920×1080、现代克制、高信息密度；禁止“AI 蓝”模板感、伪新闻画面、伪文件/聊天/UI/数据页、用生成图冒充真人或真实事件现场。

## 独立 Material Review

Reviewer 可重新打开包里已有 URL，但不能扩展研究。它检查 provenance、Claim 对齐、Rights、误导裁切、过期、身份错误、生成图 grounding、AI 图冒充事实、重复和实际用途。

Review 内容只报告 checks 和 typed issues。Issue ID、严重度、item/package Gate 和最终状态由代码拥有。危险项按 item 隔离；若仍有安全替代，包可以是 `reviewed_with_warnings`，否则阻断。

## 模块分工

- `material_schema.py`：Material / Review / Visual 的完整 JSON 契约。
- `material_profile.py`：读取并校验 Profile 0.5。
- `material_validation.py`：输入 Gate、Cue、绑定、provenance、rights、ranking、包一致性。
- `material_acquisition.py`：安全下载与本地截图登记。
- `visual_renderer.py`：确定性 SVG。
- `material_review.py`：独立 Review 和 Gate。
- `material_storage.py`：不可覆盖 JSON / Markdown / asset 历史。
- `material_workflow.py`：Codex 与 API 两条正式流程。
- `material_renderer.py`：普通用户阅读版。
- `providers/base.py` / `providers/openai.py`：`search_materials` 与 `review_materials` 边界。
- `.agents/skills/prepare-materials/`：自然语言入口。

运行数据写入被 Git 忽略的 `material_packages/` 和 `material_assets/`。公开仓库只提交虚构示例、去内容化评测、契约、测试和文档。

## 未来制作层接口

Visual Spec 提供确定的宽高、建议时长、资产路径、样式 token、composition hint 和静态/Remotion/HyperFrames candidate。未来 Remotion 可把这些字段映射为 Composition props；HyperFrames 可映射为 `data-composition-id`、尺寸、时长和 track。V0.5 不生成可播放 Composition，也不把秒数误当已经完成的音频对齐。
