# V0.5.1 Material Gate Hardening 设计

## 目标

在不扩大 V0.5 功能范围的前提下，把素材权利、原创 Visual 内部引用和已审素材包的可信状态改为可重复验证的程序规则。

## 方案

### 1. 权利的 actual-open 证明

权利记录增加 `rights_evidence_url`。一个可直接使用的静态素材必须同时满足：素材 URL 已实际打开、权利依据 URL 已实际打开、权利记录的工具引用与该依据页面的 inspection 引用相同；明确复用、CC 和官方媒体素材的 license URL 必须是公开 HTTP(S) URL，并与权利依据 URL 完全相同。无法满足时一律降为 `reference_only`，模型声称的权利状态不参与最终判断。

### 2. Visual 的嵌套 grounding

每个 timeline event、bar data point 和 comparison item 都独立校验 Claim/Evidence 存在且一一对应；顶层引用必须等于所有子项引用的确定性并集。timeline 必须精确匹配 Research timeline 的日期、Claim 组合和 Evidence 组合，label 直接取已批准 timeline event。bar 数值使用数字边界匹配，`value_label` 必须包含同一个数值。diagram node ID 唯一且每个 node 都必须引用已批准 Claim。

### 3. r1 → Review → r2 的复验链

r1 在创建时保存机器拥有的输入、inspection 和 rights provenance bundle；存储层另写不可覆盖的三个 artifact 文件。r2 加载时重新读取精确 r1、三个 provenance artifact 和 Review Artifact，重新生成 r1 的机器字段，再由 Review Artifact 确定性导出 r2。任何手改 eligibility、rights/provenance、排序、状态或 review linkage 即使重算普通 digest 也会失败关闭。

### 4. 文件与截图安全

SVG 使用 XML 解析检查真实危险结构，允许标准 namespace，拒绝脚本、事件处理器、foreignObject、javascript 和外部 href/CSS URL。截图要求 PDF 页码采用 1-based 且不小于 1，并根据文件 magic 验证 PNG/JPEG/WebP 与扩展名一致。

## 不做

不实现 Remotion、HyperFrames、完整视频、剪辑、字幕、音频、封面或发布。

## 验收

新增反篡改与边界测试；原有所有测试继续通过；仅保存去内容化评测汇总；发布公开 GitHub Release `v0.5.1`。
